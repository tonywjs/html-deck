# Claude Sonnet 5 자기 보고

**1. 산출물**
- `deck.html` 183,507 bytes, 소스 `deck-src.html` 30,823 bytes

**2. 규모**
- 7슬라이드(최소 5). 한 슬라이드 최대 장면 5개(3번), 덱 전체 최대 step 인덱스 5
- 노드 59개, 엣지 9개. 전부 1280x720, 한국어, 이모지 없음, 줄표 0

**3. 정적 검사**
- `pass: true`, 오류 0, 경고 0

**4. 사용 기능**
- fx: view 3, flow 2, pulse 2, focus 1, reset 1. 엣지 `data-flow="on"` 1개
- data-step 단일 다수, 범위 1개(2번의 "2~3장면에서만 보이는" 배지 자체가 단일과의 차이를 시연)
- 전환 프리셋 4종: zoom-in(3번), flow(4번), fade(5, 7번), zoom-out(6번)
- 여정 캔버스: 6번 `2200x720`, 장면 0 왼쪽 확대, 전체 줌아웃, 오른쪽 팬. 0.58배 축소를 감안해 글자를 25px 이상으로 올리고 라벨은 쓰지 않음
- 모든 슬라이드에 aside.notes, 7번이 편집 모드와 장면 타임라인 전담 슬라이드

**5. 어려웠던 점**
- 브라우저가 금지돼 품질 스니펫과 콘솔 검사를 실제로 돌리지 못했다. 대신 인라인 좌표로 bbox 채움을 다시 계산(74~84%)하고 모든 font-size 규칙을 하한과 대조했다.
- 정적 검사기가 태그 밖 본문에 적힌 `data-step="n"` 설명글까지 속성으로 읽어 오탐이 났다. 표기를 실체 참조로 바꿔 우회했다. (이 지적을 받아 스킬 검사기가 수정됐다.)
- 3번의 확대 전용 체크리스트를 눈으로 못 본 채 고정 높이 카드 안에 들어가게 손으로 계산해야 했다.
- 7번을 정직한 목업으로 만들면서도 실제 장면 기능으로 가르치게 구성하는 일.

# Claude Fable 5.1 자기 보고

**1. 산출물**
- `deck.html` 205,270 bytes (build-template.py로 조립, 엔진은 ~/.claude/skills/html-diagram/assets)
- 소스 `deck-src.html` 52,586 bytes (스켈레톤 구조와 플레이스홀더 4개 유지)

**2. 규모**
- 8슬라이드, 1280x720. 슬라이드당 최대 장면 3개(2, 3, 4, 7번), 총 장면 19개
- 노드 62개, 엣지 10개, 슬라이드당 캔버스 1개

**3. 정적 검사**
- `pass: true`, 오류 0, 경고 0
- 자체 추가 검사: 콘텐츠 블록 태그 균형, 줄표 0, 전 슬라이드 aside.notes, 인라인 좌표 기준 노드 bbox 80.6%(2~4, 6~8번), 82.2%(여정 5번), 62.8%(타이틀, 예외), 1280 캔버스 글자 14px 이상과 2200 캔버스 26px 이상(26 x 0.58 = 15.1)
- 브라우저 검증은 규칙에 따라 수행하지 않음

**4. 사용 기능**
- data-step: 단일 n 다수, 범위 `1-2`(2번 콜아웃), `0-0`(1번과 5번 힌트), 엣지와 노드 내부 요소에도 적용
- fx: focus 4회(3번은 zoom 1.6 딤 On과 `data-dim="false"` 각각, 7번은 타임라인과 도크 목업), view 3회(5번), flow 6회, pulse 7회, reset 2회. 엣지 `data-flow="on"` 1개, `.deck-focus` CSS 공개 사용
- 전환 프리셋: rise, zoom-in, flow, zoom-out, fade 다섯 가지 모두
- 여정 캔버스: 5번 `2200x720`, 장면 0 view(왼쪽 780), 장면 1 전체 줌아웃, 장면 2 오른쪽 팬
- 편집 모드 안내: 7번(무대, 도크, 실제 색의 장면 타임라인 목업, focus 투어, 5단계 절차), 8번에 키 치트시트

**5. 어려웠던 점**
- 브라우저 없이 검증: 고정 높이 노드를 한글과 고정폭 글꼴 줄바꿈을 손으로 추정해 잡아야 했다. 두 차례 감사해 약 15개 노드를 키우거나 줄였지만 실제 렌더링은 여전히 미확인이다.
- 검사기의 텍스트 수준 정규식이 코드 예시 안의 `data-step="n"`과 `id="..."`를 실제 속성으로 읽었다(수정 전). 그래서 코드 예시는 값을 태그로 감쌌다.
- 런타임 세부: `data-dim="false"` 인 focus는 `.deck-focus`를 붙이지 않아, 그 카드의 공개는 내부 data-step으로 대신했다. 4번 되먹임 화살표는 엔진의 곡률 공식을 따져 100px 띠 안에 머물게 했다.
